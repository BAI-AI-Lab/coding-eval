Chip Exchange

USACO 2026 First · 铜组 · 2026-01 · L1 基础 · Python 3.11 · 时限 4 秒 · 测试点等分

题面

来源：USACO 官网。模型收到的是同一份题面的文字。

Bessie the cow has in her possession $A$ chips of type A and $B$ chips of type B ($0\le A,B\le 10^9$). She can perform the following operation as many times as she likes:

  • If you have at least $c_B$ chips of type B, exchange $c_B$ chips of type B for $c_A$ chips of type A ($1\le c_A,c_B\le 10^9$).

Determine the minimum non-negative integer $x$ such that the following holds: after receiving $x$ additional random chips, it is guaranteed that Bessie can end up with at least $f_A$ chips of type A ($0\le f_A\le 10^9$).

INPUT FORMAT (input arrives from the terminal / stdin):

The first line contains $T$, the number of independent test cases ($1\le T\le 10^4$).

Then follow $T$ tests, each consisting of five integers $A,B,c_A,c_B,f_A$.

OUTPUT FORMAT (print output to the terminal / stdout):

Output the answer for each test on a separate line.

Note: The large size of integers involved in this problem may require the use of 64-bit integer data types (e.g., a "long long" in C/C++).

SAMPLE INPUT:

2
2 3 1 1 6
2 3 1 1 4

SAMPLE OUTPUT:

1
0

SAMPLE INPUT:

5
0 0 2 3 5
0 1 2 3 5
1 0 2 3 5
10 10 2 3 5
0 0 1 1000000000 1000000000

SAMPLE OUTPUT:

9
8
7
0
1000000000000000000

For the first test, Bessie initially starts with no chips. If she receives any $9$ additional chips, she can perform the operation to end up with at least $5$ chips of type A. For example, if she receives $2$ chips of type A and $7$ chips of type B, she can perform the operation twice to end up with $6\ge 5$ chips of type A. However, if she only receive $8$ chips of type B, she can only end up with $4<5$ chips of type A.

For the fourth test, she already has enough chips of type A from the start.

SCORING:

  • Input 3: $c_A=c_B=1$
  • Inputs 4-5: $x\le 10$ for all cases
  • Inputs 6-7: $c_A=2$, $c_B=3$
  • Inputs 8-12: No additional constraints.

Problem credits: Benjamin Qi

import sys


def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    T = data[0]
    pos = 1
    answers = []

    for _ in range(T):
        A, B, c_A, c_B, f_A = data[pos:pos + 5]
        pos += 5

        def guaranteed(x):
            # If t is the total number of B chips before exchanges, then
            # t ranges from B to C, and the final number of A chips is
            # A + C - H(t), where H(t) = t - c_A * floor(t / c_B).
            C = B + x

            max_h = C - c_A * (C // c_B)

            # H(t) increases within each block of c_B consecutive values.
            # Thus, besides C, only one block endpoint needs consideration.
            if c_A <= c_B:
                # Largest t <= C with t % c_B == c_B - 1.
                t = C - (C + 1) % c_B
                if t >= B:
                    h = t - c_A * (t // c_B)
                    if h > max_h:
                        max_h = h
            else:
                # Smallest t >= B with t % c_B == c_B - 1.
                t = B + ((-(B + 1)) % c_B)
                if t <= C:
                    h = t - c_A * (t // c_B)
                    if h > max_h:
                        max_h = h

            return A + C - max_h >= f_A

        if guaranteed(0):
            answers.append("0")
            continue

        lo, hi = 0, 1
        while not guaranteed(hi):
            lo = hi
            hi *= 2

        while hi - lo > 1:
            mid = (lo + hi) // 2
            if guaranteed(mid):
                hi = mid
            else:
                lo = mid

        answers.append(str(hi))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    solve()

import sys


def min_phi(L, R, cA, cB):
    """
    Returns min(cA * floor(n / cB) - n) for integer n in [L, R].
    """
    if cA >= cB:
        qL = L // cB
        end_first = (qL + 1) * cB - 1
        if end_first > R:
            end_first = R
        return cA * (end_first // cB) - end_first
    else:
        qR = R // cB
        ans = cA * qR - R

        prev_end = qR * cB - 1
        if prev_end >= L:
            val = cA * (prev_end // cB) - prev_end
            if val < ans:
                ans = val

        return ans


def solve():

    T = data[0]
    idx = 1
    answers = []

    for _ in range(T):
        A, B, cA, cB, fA = data[idx:idx + 5]
        idx += 5

        lo = -1
        hi = 10**19

        while hi - lo > 1:
            mid = (lo + hi) // 2

            # Total type B after receiving mid chips, if b of them are type B,
            # lies in [B, B + mid].
            m = min_phi(B, B + mid, cA, cB)

            # Minimum possible final number of type A chips over all ways
            # to distribute the mid extra chips.
            min_final_A = A + mid + B + m

            if min_final_A >= fA:
                hi = mid
            else:
                lo = mid

        answers.append(str(hi))

    sys.stdout.write("\n".join(answers))

import sys


def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    t = data[0]
    idx = 1
    answers = []

    for _ in range(t):
        A, B, c_A, c_B, f_A = data[idx:idx + 5]
        idx += 5

        need = f_A - A
        if need <= 0:
            answers.append("0")
            continue

        min_k = B // c_B
        max_k = (need - 1) // c_A

        # The initial chips already suffice.
        if min_k > max_k:
            answers.append("0")
            continue

        if c_B >= c_A:
            k = max_k
        else:
            k = min_k

        max_failing = need - B - 2 + c_B + k * (c_B - c_A)
        answers.append(str(max_failing + 1))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    solve()
