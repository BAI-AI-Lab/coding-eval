2^a b^2

AtCoder ABC 400 C 题 · 2025-04-05 · 中等

能写成 2ᵃ·b²（a、b 为正整数）的数称为好数；求 1 到 N 内好数的个数，N ≤ 10¹⁸。

要点：好数恰为 2m² 或 4m² 两类且互不重叠，答案为 ⌊√(N/2)⌋ + ⌊√(N/4)⌋；须用整数开方，浮点 sqrt 在 10¹⁸ 附近出错。

Kimi K3.1 Pro · 12 行
import sys
from math import isqrt

def main():
    n = int(sys.stdin.buffer.read().strip())
    # Good integers are exactly the disjoint sets:
    # (2k)^2 = 4k^2 and 2k^2, for positive integers k.
    answer = isqrt(n // 4) + isqrt(n // 2)
    print(answer)

if __name__ == "__main__":
    main()

import sys
import math

def main():
    N = int(sys.stdin.readline())
    ans = 0
    power_of_two = 2

    while power_of_two <= N:
        max_odd_square_base = math.isqrt(N // power_of_two)
        ans += (max_odd_square_base + 1) // 2
        power_of_two *= 2

    print(ans)

if __name__ == "__main__":
    main()
