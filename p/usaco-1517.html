It's Mooin' Time III

USACO 2025 US Open · 铜组 · 2025-03 · L1 基础 · Python 3.11 · 时限 4 秒 · 测试点等分

查看原题跳到结果

题面

来源：USACO 官网。模型收到的是同一份题面的文字。

Elsie is trying to describe her favorite USACO contest to Bessie, but Bessie is having trouble understanding why Elsie likes it so much. Elsie says "And It's mooin' time! Who wants a mooin'? Please, I just want to do USACO".

Bessie still doesn't understand, so she transcribes Elsie's description in a string of length $N$ ($3 \leq N \leq 10^5$) containing lowercase alphabetic characters $s_1s_2 \ldots s_N$. Elsie considers a string $t$ containing three characters a moo if $t_2 = t_3$ and $t_2 \neq t_1$.

A triplet $(i, j, k)$ is valid if $i < j < k$ and string $s_i s_j s_k$ forms a moo. For the triplet, FJ performs the following to calculate its value:

  • FJ bends string $s$ 90-degrees at index $j$
  • The value of the triplet is twice the area of $\Delta ijk$.

In other words, the value of the triplet is $(j-i)(k-j)$.

Bessie asks you $Q$ ($1 \leq Q \leq 3 \cdot 10^4$) queries. In each query, she gives you two integers $l$ and $r$ ($1 \leq l \leq r \leq N$, $r-l+1 \ge 3$) and ask you for the maximum value among valid triplets $(i, j, k)$ such that $l \leq i$ and $k \leq r$. If no valid triplet exists, output $-1$.

Note that the large size of integers involved in this problem may require the use of 64-bit integer data types (e.g., a "long long" in C/C++).

INPUT FORMAT (input arrives from the terminal / stdin):

The first line contains two integers $N$ and $Q$.

The following line contains $s_1 s_2, \ldots s_N$.

The following $Q$ lines contain two integers $l$ and $r$, denoting each query.

OUTPUT FORMAT (print output to the terminal / stdout):

Output the answer for each query on a new line.

SAMPLE INPUT:

12 5
abcabbacabac
1 12
2 7
4 8
2 5
3 10

SAMPLE OUTPUT:

28
6
1
-1
12
For the first query, ($i,j,k$) must satisfy $1 \le i < j < k \le 12$. It can be shown that the maximum area of $\Delta ijk$ for some valid ($i,j,k$) is achieved when $i=1$, $j=8$, and $k=12$. Note that $s_1 s_8 s_{12}$ is the string "acc" which is a moo according to the definitions above. $\Delta ijk$ will have legs of lengths $7$ and $4$ so two times the area of it will be $28$.

For the third query, ($i,j,k$) must satisfy $4 \le i < j < k \le 8$. It can be shown that the maximum area of $\Delta ijk$ for some valid ($i,j,k$) is achieved when $i=4$, $j=5$, and $k=6$.

For the fourth query, there exists no ($i,j,k$) satisfying $2 \le i < j < k \le 5$ in which $s_i s_j s_k$ is a moo so the output to that query is $-1$.

SCORING:

  • Inputs 2-3: $N,Q\le 50$
  • Inputs 4-6: $Q=1$ and the singular query satisfies $l=1$ and $r=N$
  • Inputs 7-11: No additional constraints

import sys
from bisect import bisect_left, bisect_right


def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    n = int(data[0])
    q = int(data[1])
    s = data[2]

    occurrences = [[] for _ in range(26)]
    for i, ch in enumerate(s):
        occurrences[ch - 97].append(i)

    # next_different[i] is the first position after i whose character
    # differs from s[i], skipping the entire run starting at i.
    next_different = [n] * n
    for i in range(n - 2, -1, -1):
        if s[i] == s[i + 1]:
            next_different[i] = next_different[i + 1]
        else:
            next_different[i] = i + 1

    answers = []
    idx = 3

    for _ in range(q):
        l = int(data[idx]) - 1
        r = int(data[idx + 1]) - 1
        idx += 2

        first_char = s[l] - 97
        after_initial_run = next_different[l]
        best = -1

        # Let y be the repeated character at positions j and k.
        for y in range(26):
            positions = occurrences[y]
            if len(positions) < 2:
                continue

            # For fixed y and j, the best i is the earliest position >= l
            # containing a character different from y.
            if y == first_char:
                i = after_initial_run
            else:
                i = l

            # For fixed i and j, using the last possible k is optimal.
            k_index = bisect_right(positions, r) - 1
            if k_index < 0:
                continue
            k = positions[k_index]

            if i >= k:
                continue

            # j must be an occurrence of y with i < j < k.
            first_j_index = bisect_right(positions, i)
            if first_j_index >= k_index:
                continue

            # (j-i)(k-j) is maximized by the available j closest to
            # the midpoint (i+k)/2. Only its neighboring occurrences
            # need to be checked.
            target = (i + k) // 2
            p = bisect_left(
                positions, target, first_j_index, k_index
            )

            if p < k_index:
                j = positions[p]
                value = (j - i) * (k - j)
                if value > best:
                    best = value

            if p > first_j_index:
                j = positions[p - 1]
                value = (j - i) * (k - j)
                if value > best:
                    best = value

        answers.append(str(best))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    main()

import sys
from bisect import bisect_left, bisect_right


def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0])
    Q = int(data[1])
    s = data[2]

    run_end = [0] * N
    run_end[N - 1] = N - 1
    for i in range(N - 2, -1, -1):
        if s[i] == s[i + 1]:
            run_end[i] = run_end[i + 1]
        else:
            run_end[i] = i

    positions = [[] for _ in range(26)]
    for i, ch in enumerate(s):
        positions[ch - 97].append(i)

    queries = []
    p = 3
    for qi in range(Q):
        l = int(data[p]) - 1
        r = int(data[p + 1]) - 1
        p += 2
        queries.append((r, l, qi))

    queries.sort()

    answers = [-1] * Q
    last = [-1] * 26
    cur = -1

    for r, l, qi in queries:
        while cur < r:
            cur += 1
            last[s[cur] - 97] = cur

        sl = s[l] - 97
        d_same = run_end[l] + 1
        best = -1

        for c in range(26):
            R = last[c]
            if R < 0:
                continue

            if c == sl:
                d = d_same
            else:
                d = l

            if R <= d + 1:
                continue

            pos = positions[c]
            lo = bisect_right(pos, d)
            hi = bisect_left(pos, R)

            if lo >= hi:
                continue

            target = (d + R) // 2
            idx = bisect_left(pos, target, lo, hi)

            if idx < hi:
                j = pos[idx]
                val = (j - d) * (R - j)
                if val > best:
                    best = val

            if idx > lo:
                j = pos[idx - 1]
                val = (j - d) * (R - j)
                if val > best:
                    best = val

        answers[qi] = best

    sys.stdout.write("\n".join(map(str, answers)))


if __name__ == "__main__":
    main()

import sys
from bisect import bisect_left


def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    n = int(data[0])
    q = int(data[1])
    s = data[2]
    codes = [ch - 97 for ch in s]

    # occurrence lists (1-indexed positions)
    pos = [[] for _ in range(26)]
    for i, ch in enumerate(codes, 1):
        pos[ch].append(i)
    plen = [len(p) for p in pos]

    # prev[c][r] = last index <= r holding character c (0 if none)
    prev = [None] * 26
    for c in range(26):
        p = pos[c]
        if not p:
            prev[c] = [0] * (n + 1)
            continue
        arr = [0] * p[0]
        for i in range(len(p) - 1):
            arr.extend([p[i]] * (p[i + 1] - p[i]))
        arr.extend([p[-1]] * (n + 1 - p[-1]))
        prev[c] = arr

    # run_end[i] = last index of the run of equal characters containing i
    run_end = [0] * (n + 1)
    i = 1
    while i <= n:
        j = i
        c = codes[i - 1]
        while j < n and codes[j] == c:
            j += 1
        for t in range(i, j + 1):
            run_end[t] = j
        i = j + 1

    out = []
    ptr = 3
    bl = bisect_left
    for _ in range(q):
        l = int(data[ptr])
        r = int(data[ptr + 1])
        ptr += 2
        cl = codes[l - 1]
        i_same = run_end[l] + 1          # first index >= l with char != s[l]
        best = -1
        for c in range(26):
            p = pos[c]
            if not p:
                continue
            K = prev[c][r]               # largest k <= r with s[k] == c
            I = i_same if c == cl else l  # smallest i >= l with s[i] != c
            if K - I < 2:
                continue                  # need I < j < K
            t = (I + K) >> 1
            b = bl(p, t)
            if b:
                j = p[b - 1]
                if j > I:
                    v = (j - I) * (K - j)
                    if v > best:
                        best = v
            if b < plen[c]:
                j = p[b]
                if j < K:
                    v = (j - I) * (K - j)
                    if v > best:
                        best = v
        out.append(str(best))

    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    solve()
