题面

来源：USACO 官网。模型收到的是同一份题面的文字。

Farmer John is expanding his farm! He has identified the perfect location in the Red-Black Forest, which consists of $N$ trees ($1 \le N \le 10^5$) on a number line, with the $i$-th tree at position $x_i$ ($-10^9 \le x_i \le 10^9$).

Environmental protection laws restrict which trees Farmer John can cut down to make space for his farm. There are $K$ restrictions ($1 \leq K \leq 10^5$) specifying that there must always be at least $t_i$ trees ($1 \leq t_i \leq N$) in the line segment $[l_i, r_i]$, including the endpoints ($-10^9 \le l_i \leq r_i \le 10^9$). It is guaranteed that the Red-Black Forest initially satisfies these restrictions.

Farmer John wants to make his farm as big as possible. Please help him compute the maximum number of trees he can cut down while still satisfying all the restrictions!

INPUT FORMAT (input arrives from the terminal / stdin):

Each input consists of $T$ ($1 \le T \le 10$) independent test cases. It is guaranteed that the sums of all $N$ and of all $K$ within an input each do not exceed $3 \cdot 10^5$.

The first line of input contains $T$. Each test case is then formatted as follows:

  • The first line contains integers $N$ and $K$.
  • The next line contains the $N$ integers $x_1, \dots, x_N$.
  • Each of the next $K$ lines contains three space-separated integers: $l_i$, $r_i$ and $t_i$.

OUTPUT FORMAT (print output to the terminal / stdout):

For each test case, output a single line with an integer denoting the maximum number of trees Farmer John can cut down.

SAMPLE INPUT:

3
7 1
8 4 10 1 2 6 7
2 9 3
7 2
8 4 10 1 2 6 7
2 9 3
1 10 1
7 2
8 4 10 1 2 6 7
2 9 3
1 10 4

SAMPLE OUTPUT:

4
4
3

For the first test case, Farmer John can cut down the first $4$ trees, leaving trees at $x_i = 2, 6, 7$ to satisfy the restriction.

For the second test case, the additional restriction does not affect which trees Farmer John can cut down, so he can cut down the same trees and satisfy both restrictions.

For the third test case, Farmer John can only cut down at most $3$ trees because there are initially $7$ trees but the second restriction requires him to leave at least $4$ trees uncut.

SCORING:

  • Input 2: $N, K \le 16$
  • Inputs 3-5: $N, K \le 1000$
  • Inputs 6-7: $t_i = 1$ for all $i = 1, \dots, K$.
  • Inputs 8-11: No additional constraints.

Problem credits: Tina Wang, Jiahe Lu, Benjamin Qi

import sys
from bisect import bisect_left, bisect_right


def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    pos = 0
    t_cases = data[pos]
    pos += 1
    answers = []

    for _ in range(t_cases):
        n, k = data[pos], data[pos + 1]
        pos += 2

        trees = sorted(data[pos:pos + n])
        pos += n

        restrictions = []
        for _ in range(k):
            l, r, required = data[pos], data[pos + 1], data[pos + 2]
            pos += 3

            # Convert coordinates to 1-based indices in the sorted tree array.
            left = bisect_left(trees, l) + 1
            right = bisect_right(trees, r)
            restrictions.append((r, right, left, required))

        restrictions.sort(key=lambda x: x[0])

        bit = [0] * (n + 1)

        def bit_sum(index):
            result = 0
            while index > 0:
                result += bit[index]
                index -= index & -index
            return result

        def bit_add(index):
            while index <= n:
                bit[index] += 1
                index += index & -index

        # parent[i] leads to the rightmost unselected tree at or before i.
        parent = list(range(n + 1))

        def find(index):
            while parent[index] != index:
                parent[index] = parent[parent[index]]
                index = parent[index]
            return index

        kept = 0

        for _, right, left, required in restrictions:
            already_kept = bit_sum(right) - bit_sum(left - 1)
            needed = required - already_kept

            while needed > 0:
                chosen = find(right)
                bit_add(chosen)
                parent[chosen] = find(chosen - 1)
                kept += 1
                needed -= 1

        answers.append(str(n - kept))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    solve()

            r = next(it)

            b = bisect.bisect_right(xs, r)

        kept = 0

            root = x

                root = parent[root]

                nxt = parent[x]
                parent[x] = root
                x = nxt

import sys
from bisect import bisect_left, bisect_right


def solve():
    data = iter(map(int, sys.stdin.buffer.read().split()))
    try:
        test_cases = next(data)
    except StopIteration:
        return

    answers = []

    for _case in range(test_cases):
        n = next(data)
        k = next(data)

        positions = [next(data) for _ in range(n)]
        positions.sort()

        restrictions = []
        for _ in range(k):
            l = next(data)
            r = next(data)
            required = next(data)

            # Convert the coordinate interval to a 1-based index interval.
            left = bisect_left(positions, l) + 1
            right = bisect_right(positions, r)
            restrictions.append((right, left, required))

        # Process intervals in increasing order of their right endpoint.
        restrictions.sort()

        # Predecessor DSU: find(v) is the largest not-yet-kept index <= v.
        # Index 0 is a sentinel.
        parent = list(range(n + 1))

        def find(v):
            while parent[v] != v:
                parent[v] = parent[parent[v]]
                v = parent[v]
            return v

        # Fenwick tree containing 1 at each kept tree's index.
        bit = [0] * (n + 1)
        kept = 0

        for right, left, required in restrictions:
            # Count kept trees strictly before left.
            before = 0
            j = left - 1
            while j:
                before += bit[j]
                j -= j & -j

            # All trees kept so far have index <= right, so this is the
            # number of kept trees in [left, right].
            need = required - (kept - before)
            if need <= 0:
                continue

            # Keep the rightmost available trees in the interval.
            # Initial feasibility guarantees that these indices are >= left.
            p = find(right)
            while need > 0:
                q = find(p - 1)
                parent[p] = q

                j = p
                while j <= n:
                    bit[j] += 1
                    j += j & -j

                kept += 1
                need -= 1
                p = q

        answers.append(str(n - kept))

    sys.stdout.write("\n".join(answers) + "\n")


if __name__ == "__main__":
    solve()
