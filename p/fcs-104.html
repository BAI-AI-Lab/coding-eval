Time Limit: 2 s Memory Limit: 256 MB This is an interactive problem. There are n students, having roll numbers 1 to n. Mr. 1048576 knows that exactly 1 student is absent today. In order to determine who is absent, he can ask some queries to the class. In each query, he provide two integers l and r (1≤l≤r≤n) and all students whose roll numbers are between l and r (inclusive) are expected to raise their hands. But the students are dishonest. Some students whose roll numbers lie in the given range may not raise their hands, while some other students whose roll number does not lie in the given range may raise their hands. But only the following 4 cases are possible for a particular query (l,r) — 1. True Positive: r−l+1 students are present and r−l+1 students raised their hands. 2. True Negative: r−l students are present and r−l students raised their hands. 3. False Positive: r−l students are present but r−l+1 students raised their hands. 4. False Negative: r−l+1 students are present but r−l students raised their hands. In the first two cases, the students are said to be answering honestly, while in the last two cases, the students are said to be answering dishonestly. The students can mutually decide upon their strategy, not known to Mr. 1048576. Also, their strategy always meets the following two conditions — 1. The students will never answer honestly 3 times in a row. 2. The students will never answer dishonestly 3 times in a row. Mr. 1048576 is willing to mark at most 2 students as absent (though he knows that only one is). The attendance is said to be successful if the student who is actually absent is among those two. Also, he can only ask up to 2* ⌈log_{1.116}n⌉ queries. Help him complete a successful attendance. Interaction First read a line containing a single integer t (1≤t≤2048) denoting the number of independent test cases that you must solve. For each test case, first read a line containing a single integer n (5≤n≤10^5). Then you may ask up to 2* ⌈log_{1.116}n⌉ queries. Your score depends on the query count as specified below. To ask a query, print a single line in the format "? l r" (without quotes) (1≤l≤r≤n). Then read a single line containing a single integer x (r−l≤x≤r−l+1) denoting the number of students who raised their hands corresponding to the query. To mark a student as absent, print a single line in the format "! a" (without quotes) (1≤a≤n). Then read a single integer y (y∈{0,1}). If the student with roll number a was absent, y=1, else, y=0. Note that this operation does not count as a query but you can do this operation at most 2 times. To end a test case, print a single line in the format "#" (without quotes). Then you must continue solving the remaining test cases. The sum of n over all test cases does not exceed 10^5. To flush the buffer, use fflush(stdout) or cout.flush() The answer may change depending on your queries but will always remain consistent with the constraints and the answer to the previous queries. Points are averaged over test files. For the logarithmic branch, write x for the original minimizing quantity and a for its physical 60-point reference. The improvement factor is r=a/x, and the upper-band award is P=min(100,60+ln(r)). Here ln is natural: r=1 corresponds to 60 points, and on the uncapped logarithmic upper band, r=exp(P-60). Each additional point multiplies the physical improvement factor by e (divides a minimizing objective by e or multiplies a maximizing objective by e, as applicable). The lower-band, zero-objective, and completion rules below still apply. For subcase j, let Q_j be its query count and L_j>1 its query limit. Define the per-subcase physical reference a_j=A_j=0.4*L_j+0.6 and B_j=100*min(1,max(0,(L_j-Q_j)/(L_j-1))). Guess actions are not queries. const int NXT[4][2] = {
    {1, 2},
    {-1, 2},
    {0, 3},
    {0, -1}
};

struct Endgame {
    static const int INF = 1000000000;
    vector<int> dist, move;
    vector<vector<int>> patterns;

    static int nextConfig(int key, int qmask, int reply) {
        int m = key >> 8;
        int states = key & 255;
        int newMask = 0, newM = 0;

        for (int i = 0; i < m; i++) {
            int s = (states >> (2 * i)) & 3;
            int b = (qmask >> i) & 1;
            int h = reply ^ b;
            int ns = NXT[s][h];
            if (ns != -1) {
                newMask |= ns << (2 * newM);
                newM++;
            }
        }

        if (newM <= 2) return -1;
        return (newM << 8) | newMask;
    }

    Endgame() {
        dist.assign(5 << 8, INF);
        move.assign(5 << 8, -1);
        patterns.resize(5);

        for (int m = 3; m <= 4; m++) {
            for (int i = 0; i < m; i++) {
                for (int j = i; j < m; j++) {
                    int mask = 0;
                    for (int k = i; k <= j; k++) mask |= 1 << k;
                    patterns[m].push_back(mask);
                }
            }
        }

        vector<int> configs;
        for (int m = 3; m <= 4; m++) {
            int lim = 1 << (2 * m);
            for (int mask = 0; mask < lim; mask++) {
                configs.push_back((m << 8) | mask);
            }
        }

        for (int pass = 0; pass < 1000; pass++) {
            bool changed = false;

            for (int key : configs) {
                int m = key >> 8;
                int best = dist[key];
                int bestMove = move[key];

                for (int qmask : patterns[m]) {
                    bool ok = true;
                    int worst = 0;

                    for (int reply = 0; reply < 2; reply++) {
                        int nk = nextConfig(key, qmask, reply);
                        if (nk == -1) continue;
                        if (dist[nk] >= INF) {
                            ok = false;
                            break;
                        }
                        worst = max(worst, dist[nk]);
                    }

                    if (ok && worst + 1 < best) {
                        best = worst + 1;
                        bestMove = qmask;
                    }
                }

                if (best < dist[key]) {
                    dist[key] = best;
                    move[key] = bestMove;
                    changed = true;
                }
            }

            if (!changed) break;
        }
    }
};

#include <bits/stdc++.h>
using namespace std;

struct Candidate {
    int roll;
    int h = 0;
    int run = 0;
};

static vector<Candidate> applyAnswer(const vector<Candidate>& cs,
                                     const vector<int>& z, int y) {
    vector<Candidate> nxt;
    for (int i = 0; i < (int)cs.size(); ++i) {
        int required = y ^ z[i];
        Candidate d = cs[i];

        if (d.run == 0) {
            d.h = required;
            d.run = 1;
        } else {
            if (d.run == 2 && required == d.h) continue;
            if (required == d.h) {
                d.run = 2;
            } else {
                d.h = required;
                d.run = 1;
            }
        }
        nxt.push_back(d);
    }
    return nxt;
}

static const vector<pair<int, int>> smallBounds = {
    {0, 0}, {0, 1}, {0, 2}, {1, 1}, {1, 2}, {2, 2}
};

static vector<vector<int>> smallPatterns() {
    vector<vector<int>> p;
    for (auto [a, b] : smallBounds) {
        vector<int> z(3, 0);
        for (int i = a; i <= b; ++i) z[i] = 1;
        p.push_back(z);
    }
    return p;
}

static const vector<vector<int>> patterns3 = smallPatterns();
static unordered_map<string, int> memoSmall;
static unordered_map<string, int> choiceSmall;

static string smallKey(const vector<Candidate>& cs, int depth) {
    string s = to_string(depth) + ":";
    for (const auto& c : cs) {
        s.push_back(char('0' + c.h * 2 + (c.run - 1)));
        s.push_back(',');
    }
    return s;
}

static bool solveSmall(const vector<Candidate>& cs, int depth) {
    if ((int)cs.size() <= 2) return true;
    if (depth == 0) return false;

    string key = smallKey(cs, depth);
    auto it = memoSmall.find(key);
    if (it != memoSmall.end()) return it->second;

    for (int p = 0; p < 6; ++p) {
        bool ok = true;
        for (int y = 0; y <= 1; ++y) {
            vector<Candidate> nxt = applyAnswer(cs, patterns3[p], y);
            if (!nxt.empty() && !solveSmall(nxt, depth - 1)) {
                ok = false;
                break;
            }
        }
        if (ok) {
            memoSmall[key] = 1;
            choiceSmall[key] = p;
            return true;
        }
    }

    memoSmall[key] = 0;
    return false;
}

#include <bits/stdc++.h>
using namespace std;

struct Candidate {
    int pos;
    int group;
    int older = -1;
    int last = -1;
    bool alive = true;
};

class ThreeCandidateSolver {
    static constexpr int STATES = 125;
    static constexpr int INF = 1e9;

    int pw[3] = {1, 5, 25};
    const array<int, 7> masks = {0, 1, 2, 3, 4, 6, 7};

    int aliveCount(int state) const {
        int result = 0;
        for (int i = 0; i < 3; ++i) {
            int digit = (state / pw[i]) % 5;
            if (digit != 4) ++result;
        }
        return result;
    }

    int transition(int state, int mask, int response) const {
        int nextState = 0;

        for (int i = 0; i < 3; ++i) {
            int digit = (state / pw[i]) % 5;

            if (digit == 4) {
                nextState += 4 * pw[i];
                continue;
            }

            int older = digit >> 1;
            int last = digit & 1;
            int inside = (mask >> i) & 1;
            int honest = response ^ inside;

            if (older == last && last == honest) {
                digit = 4;
            } else {
                digit = (last << 1) | honest;
            }

            nextState += digit * pw[i];
        }

        return nextState;
    }

public:
    array<int, STATES> distance{};
    array<int, STATES> action{};

    ThreeCandidateSolver() {
        distance.fill(INF);
        action.fill(-1);

        for (int state = 0; state < STATES; ++state) {
            if (aliveCount(state) <= 2) {
                distance[state] = 0;
            }
        }

        bool changed = true;
        while (changed) {
            changed = false;

            for (int state = 0; state < STATES; ++state) {
                if (distance[state] != INF) continue;

                int bestDistance = INF;
                int bestAction = -1;

                for (int mask : masks) {
                    bool possible = true;
                    int maximumNextDistance = 0;

                    for (int response = 0; response <= 1; ++response) {
                        int nextState = transition(state, mask, response);

                        if (distance[nextState] == INF) {
                            possible = false;
                            break;
                        }

                        maximumNextDistance =
                            max(maximumNextDistance, distance[nextState]);
                    }

                    if (possible && maximumNextDistance + 1 < bestDistance) {
                        bestDistance = maximumNextDistance + 1;
                        bestAction = mask;
                    }
                }

                if (bestAction != -1) {
                    distance[state] = bestDistance;
                    action[state] = bestAction;
                    changed = true;
                }
            }
        }
    }
};

static int ask(int l, int r) {
    cout << "? " << l << ' ' << r << endl;

    int x;
    if (!(cin >> x)) exit(0);

    return x - (r - l);
}

static void applyResponse(vector<Candidate> &candidates, int response,
                          int selectedGroup) {
    for (Candidate &candidate : candidates) {
        if (!candidate.alive) continue;

        int inside = (candidate.group == selectedGroup);
        int honest = response ^ inside;

        if (candidate.older == candidate.last &&
            candidate.last == honest) {
            candidate.alive = false;
        } else {
            candidate.older = candidate.last;
            candidate.last = honest;
        }
    }
}

static void removeDead(vector<Candidate> &candidates) {
    vector<Candidate> remaining;
    remaining.reserve(candidates.size());

    for (const Candidate &candidate : candidates) {
        if (candidate.alive) remaining.push_back(candidate);
    }

    candidates.swap(remaining);
}

static pair<int, int> intervalForMask(const vector<Candidate> &candidates,
                                      int mask, int n) {
    if (mask == 0) {
        int freePosition = 1;
        while (freePosition <= n &&
               (freePosition == candidates[0].pos ||
                freePosition == candidates[1].pos ||
                freePosition == candidates[2].pos)) {
            ++freePosition;
        }
        return {freePosition, freePosition};
    }

    if (mask == 1) return {candidates[2].pos, candidates[2].pos};
    if (mask == 2) return {candidates[1].pos, candidates[1].pos};
    if (mask == 3) return {candidates[1].pos, candidates[2].pos};
    if (mask == 4) return {candidates[0].pos, candidates[0].pos};
    if (mask == 6) return {candidates[0].pos, candidates[1].pos};
    return {candidates[0].pos, candidates[2].pos};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;

    ThreeCandidateSolver solver;

    while (t--) {
        int n;
        cin >> n;

        vector<Candidate> candidates;
        candidates.reserve(n);

        for (int position = 1; position <= n; ++position) {
            candidates.push_back({position, -1, -1, -1, true});
        }

        while (candidates.size() > 3) {
            int m = static_cast<int>(candidates.size());
            int groupSize[4];
            int base = m / 4;
            int remainder = m % 4;

            for (int group = 0; group < 4; ++group) {
                groupSize[group] = base + (group < remainder);
            }

            int index = 0;
            for (int group = 0; group < 4; ++group) {
                for (int j = 0; j < groupSize[group]; ++j) {
                    candidates[index++].group = group;
                }
            }

            int starts[4];
            starts[0] = 0;
            for (int group = 1; group < 4; ++group) {
                starts[group] = starts[group - 1] + groupSize[group - 1];
            }

            for (int selectedGroup = 1; selectedGroup <= 3; ++selectedGroup) {
                int l = candidates[starts[selectedGroup]].pos;
                int r = candidates[starts[selectedGroup] +
                                   groupSize[selectedGroup] - 1].pos;

                int response = ask(l, r);
                applyResponse(candidates, response, selectedGroup);
            }

            removeDead(candidates);
        }

        if (candidates.size() == 3) {
            while (candidates.size() == 3) {
                int state = 0;

                for (int i = 0; i < 3; ++i) {
                    int pairCode = (candidates[i].older << 1) |
                                   candidates[i].last;
                    state += pairCode * (i == 0 ? 1 : (i == 1 ? 5 : 25));
                }

                int mask = solver.action[state];
                if (mask == -1) {
                    mask = 7;
                }

                auto [l, r] = intervalForMask(candidates, mask, n);
                int response = ask(l, r);

                for (int i = 0; i < 3; ++i) {
                    if (!candidates[i].alive) continue;

                    int inside = (mask >> i) & 1;
                    int honest = response ^ inside;

                    if (candidates[i].older == candidates[i].last &&
                        candidates[i].last == honest) {
                        candidates[i].alive = false;
                    } else {
                        candidates[i].older = candidates[i].last;
                        candidates[i].last = honest;
                    }
                }

                removeDead(candidates);
            }
        }

        if (!candidates.empty()) {
            cout << "! " << candidates[0].pos << endl;

            int result;
            cin >> result;

            if (result == 0 && candidates.size() > 1) {
                cout << "! " << candidates[1].pos << endl;
                cin >> result;
            }
        }

        cout << "#" << endl;
    }

    return 0;
}
