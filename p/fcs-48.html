Sphere Packing in a Cube (Optimization) You are given an integer n. Place n pairwise-disjoint congruent solid spheres inside the unit cube [0, 1]^3 so that the common radius is as large as possible. You do not need to output the radius explicitly; the checker infers the largest valid common radius from your centers. Input The input consists of a single line with one integer: n (2 ≤ n ≤ 10^6 in principle; in the official tests n ≤ 4096.) Output Output exactly n lines. Each line must contain three real numbers x y z (in any standard real-number format parseable by C/C++, e.g., 0.0, 1, 1e-3), giving the coordinates of a sphere center. All coordinates must satisfy 0 ≤ x, y, z ≤ 1. Whitespace is free; no additional text is allowed. Trailing whitespace is ignored. Feasibility & how the checker interprets your output Given your centers C = {c_i}, the checker computes the largest common radius that makes the spheres non-overlapping and contained in the cube, completely ignoring any radius you might have assumed. Formally, your geometric radius is r(C) = min( ½ * min_{i≠j} ||c_i - c_j||_2 , min_i dist(c_i, ∂[0,1]^3) ), where dist(c_i, ∂[0,1]^3) is the minimum distance from c_i to any cube face. If any coordinate lies outside [0,1] (up to an absolute tolerance of 1e−12), the output is rejected. ## Scoring Let x be rho, the geometric sphere radius. B and R are the baseline and comparison radii stored with the test. If R<=B+1e-15, use the separate rule: 60 if rho+1e-18>=R, otherwise 0. These tolerances are absolute. The physical reference (the 60-point level) is a=R. Define the lower-band continuation: L(x) = 60*max(0,(x-B)/(R-B)). For positive x and positive physical reference a, define the improvement factor r=x/a. The physical reference has r=1 and earns 60 points. For a valid output on this branch, the points P are: P = L(x), if L(x)<=60; P = min(100,60+ln(r)), otherwise. Here ln is the natural logarithm. In the upper branch before the 100-point cap, r=exp(P-60): each additional point requires an e-fold improvement in the physical objective (multiplication by e). A zero maximization objective is not a full-score exception. All feasibility, correctness, and hard resource-limit checks remain required; invalid output receives 0. Across test files, use the arithmetic mean of the file scores. Validation & precision • The checker reads doubles and computes in IEEE-754 double precision. It accepts coordinates on the faces of the cube. • The checker rejects outputs that do not contain exactly n triples, that contain non-finite numbers, or that place any center outside [0,1]. • Distances are computed exactly as written above; there is no relative/absolute tolerance applied to r(C) beyond floating-point rounding. • The checker runs in O(n^2) on your centers (only 8.4 million pairs at n=4096), so keep n modest if you test locally. Example Input 5 Valid Output (one of many) 0.1 0.1 0.1 0.9 0.1 0.1 0.1 0.9 0.1 0.1 0.1 0.9 0.9 0.9 0.9 (Your solution is free to produce any arrangement.) Notes • You only need to output centers. The checker automatically determines the maximum common radius supported by your centers. • Greedy / local-improvement heuristics, lattice-based constructions, simulated annealing, or nonlinear optimization often yield good packings. • Touching spheres and touching the cube faces are allowed; overlaps are not.

#include <bits/stdc++.h>
using namespace std;

struct Vec3 {
    double x = 0, y = 0, z = 0;
};

static inline Vec3 operator+(const Vec3& a, const Vec3& b) {
    return {a.x + b.x, a.y + b.y, a.z + b.z};
}
static inline Vec3 operator-(const Vec3& a, const Vec3& b) {
    return {a.x - b.x, a.y - b.y, a.z - b.z};
}
static inline Vec3 operator*(const Vec3& a, double s) {
    return {a.x * s, a.y * s, a.z * s};
}
static inline double dot(const Vec3& a, const Vec3& b) {
    return a.x * b.x + a.y * b.y + a.z * b.z;
}
static inline Vec3 cross(const Vec3& a, const Vec3& b) {
    return {a.y * b.z - a.z * b.y,
            a.z * b.x - a.x * b.z,
            a.x * b.y - a.y * b.x};
}
static inline double norm2(const Vec3& a) {
    return dot(a, a);
}

struct Builder {
    int n;
    vector<Vec3> best;
    vector<Vec3> bestRaw;
    double bestR = 0.0;

    explicit Builder(int n_) : n(n_) {}

    double anisotropic(const vector<Vec3>& p, vector<Vec3>& out) const {
        Vec3 lo{1e100, 1e100, 1e100}, hi{-1e100, -1e100, -1e100};
        for (const auto& a : p) {
            lo.x = min(lo.x, a.x); lo.y = min(lo.y, a.y); lo.z = min(lo.z, a.z);
            hi.x = max(hi.x, a.x); hi.y = max(hi.y, a.y); hi.z = max(hi.z, a.z);
        }
        Vec3 span{hi.x - lo.x, hi.y - lo.y, hi.z - lo.z};
        vector<Vec3> q(n);
        for (int i = 0; i < n; ++i) {
            q[i].x = span.x > 1e-15 ? (p[i].x - lo.x) / span.x : 0.5;
            q[i].y = span.y > 1e-15 ? (p[i].y - lo.y) / span.y : 0.5;
            q[i].z = span.z > 1e-15 ? (p[i].z - lo.z) / span.z : 0.5;
        }
        double q2 = 1e100;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                q2 = min(q2, norm2(q[i] - q[j]));
            }
        }
        if (!(q2 > 1e-30) || !isfinite(q2)) return 0.0;
        double qm = sqrt(q2);
        double r = qm / (2.0 * (1.0 + qm));
        double mul = 1.0 - 2.0 * r;
        out.resize(n);
        for (int i = 0; i < n; ++i) {
            out[i] = {r + mul * q[i].x, r + mul * q[i].y, r + mul * q[i].z};
        }
        return r;
    }

    void consider(const vector<Vec3>& p, double latticeDistance) {
        if ((int)p.size() != n) return;

        if (n <= 700) {
            vector<Vec3> c;
            double r = anisotropic(p, c);
            if (r > bestR) {
                bestR = r;
                best = std::move(c);
            }
            return;
        }

        Vec3 lo{1e100, 1e100, 1e100}, hi{-1e100, -1e100, -1e100};
        for (const auto& a : p) {
            lo.x = min(lo.x, a.x); lo.y = min(lo.y, a.y); lo.z = min(lo.z, a.z);
            hi.x = max(hi.x, a.x); hi.y = max(hi.y, a.y); hi.z = max(hi.z, a.z);
        }
        double S = max({hi.x - lo.x, hi.y - lo.y, hi.z - lo.z});
        if (!(S > 1e-15)) return;
        double scale = 1.0 / (S + latticeDistance);
        double r = 0.5 * latticeDistance * scale;
        if (r <= bestR * (1.0 + 1e-13)) return;

        Vec3 mid{(lo.x + hi.x) * 0.5, (lo.y + hi.y) * 0.5, (lo.z + hi.z) * 0.5};
        vector<Vec3> c(n);
        for (int i = 0; i < n; ++i) {
            c[i] = {0.5 + (p[i].x - mid.x) * scale,
                    0.5 + (p[i].y - mid.y) * scale,
                    0.5 + (p[i].z - mid.z) * scale};
        }
        bestR = r;
        best = std::move(c);
        bestRaw = p;
    }

    struct Item {
        Vec3 p;
        double k1, k2;
        int id;
    };

    void processBase(const vector<Vec3>& base, double d, const vector<Vec3>& offsets) {
        if ((int)base.size() < n) return;
        vector<Item> a(base.size());
        for (const Vec3& off : offsets) {
            for (int i = 0; i < (int)base.size(); ++i) {
                double dx = base[i].x - off.x;
                double dy = base[i].y - off.y;
                double dz = base[i].z - off.z;
                a[i].p = base[i];
                a[i].k1 = max({fabs(dx), fabs(dy), fabs(dz)});
                a[i].k2 = dx * dx + dy * dy + dz * dz;
                a[i].id = i;
            }
            auto cmp = [](const Item& u, const Item& v) {
                if (u.k1 != v.k1) return u.k1 < v.k1;
                if (u.k2 != v.k2) return u.k2 < v.k2;
                return u.id < v.id;
            };
            if ((int)a.size() > n) {
                nth_element(a.begin(), a.begin() + n, a.end(), cmp);
                a.resize(n);
            }
            vector<Vec3> raw;
            raw.reserve(n);
            for (const auto& it : a) raw.push_back(it.p);
            consider(raw, d);
        }
    }

    static vector<Vec3> centralSubset(const vector<Vec3>& input, int wanted, const Vec3& center) {
        if ((int)input.size() <= wanted) return input;
        vector<Item> a(input.size());
        for (int i = 0; i < (int)input.size(); ++i) {
            a[i].p = input[i];
            a[i].k1 = norm2(input[i] - center);
            a[i].k2 = 0;
            a[i].id = i;
        }
        auto cmp = [](const Item& u, const Item& v) {
            if (u.k1 != v.k1) return u.k1 < v.k1;
            return u.id < v.id;
        };
        nth_element(a.begin(), a.begin() + wanted, a.end(), cmp);
        a.resize(wanted);
        vector<Vec3> ans;
        ans.reserve(wanted);
        for (const auto& it : a) ans.push_back(it.p);
        return ans;
    }

    void finishLargeCandidate() {
        if (n > 700 && !bestRaw.empty()) {
            vector<Vec3> c;
            double r = anisotropic(bestRaw, c);
            if (r > bestR) {
                bestR = r;
                best = std::move(c);
            }
        }
    }
};

struct Optimizer {
    int n;
    vector<Vec3>& best;
    double& bestR;
    mt19937_64& rng;
    chrono::steady_clock::time_point deadline;

    struct Eval {
        double energy = 0, maxOverlap = 0, actual = -1, force2 = 0;
    };
    struct Result {
        vector<Vec3> x;
        bool feasible = false;
    };

    Optimizer(int n_, vector<Vec3>& b, double& r, mt19937_64& g,
              chrono::steady_clock::time_point dl)
        : n(n_), best(b), bestR(r), rng(g), deadline(dl) {}

    Eval evaluate(const vector<Vec3>& x, double R, vector<Vec3>& f) {
        const double D = 2.0 * R;
        const double D2 = D * D;
        f.assign(n, Vec3{});
        Eval e;
        double wall = 1e100;
        double minOverlappingDistance = D;
        bool pairOverlap = false;

        auto doWall = [&](double v, double& force) {
            wall = min(wall, v);
            wall = min(wall, 1.0 - v);
            if (v < R) {
                double o = R - v;
                e.energy += 0.5 * o * o;
                e.maxOverlap = max(e.maxOverlap, o);
                force += o;
            } else if (v > 1.0 - R) {
                double o = v - (1.0 - R);
                e.energy += 0.5 * o * o;
                e.maxOverlap = max(e.maxOverlap, o);
                force -= o;
            }
        };

        for (int i = 0; i < n; ++i) {
            doWall(x[i].x, f[i].x);
            doWall(x[i].y, f[i].y);
            doWall(x[i].z, f[i].z);
        }

        auto doPair = [&](int i, int j) {
            Vec3 delta = x[i] - x[j];
            double d2 = norm2(delta);
            if (d2 >= D2) return;
            double d = sqrt(max(0.0, d2));
            double ux, uy, uz;
            if (d > 1e-14) {
                ux = delta.x / d; uy = delta.y / d; uz = delta.z / d;
            } else {
                d = 0;
                if ((i + j) & 1) {
                    ux = 1; uy = 0; uz = 0;
                } else {
                    ux = 0; uy = 1; uz = 0;
                }
            }
            double o = D - d;
            e.energy += 0.5 * o * o;
            e.maxOverlap = max(e.maxOverlap, o);
            pairOverlap = true;
            minOverlappingDistance = min(minOverlappingDistance, d);
            f[i].x += o * ux; f[i].y += o * uy; f[i].z += o * uz;
            f[j].x -= o * ux; f[j].y -= o * uy; f[j].z -= o * uz;
        };

        bool useGrid = n > 256;
        if (useGrid) {
            int g = (int)floor(1.0 / D);
            g = max(g, 1);
            long long cells = 1LL * g * g * g;
            if (cells > 1000000) {
                useGrid = false;
            } else {
                vector<int> head((size_t)cells, -1), nxt(n, -1);
                auto coordinateCell = [&](double v) {
                    int c = (int)floor(v * g);
                    return max(0, min(g - 1, c));
                };
                auto cellId = [&](int a, int b, int c) {
                    return (a * g + b) * g + c;
                };
                for (int i = 0; i < n; ++i) {
                    int id = cellId(coordinateCell(x[i].x),
                                    coordinateCell(x[i].y),
                                    coordinateCell(x[i].z));
                    nxt[i] = head[id];
                    head[id] = i;
                }
                for (int i = 0; i < n; ++i) {
                    int cx = coordinateCell(x[i].x);
                    int cy = coordinateCell(x[i].y);
                    int cz = coordinateCell(x[i].z);
                    for (int dx = -1; dx <= 1; ++dx) {
                        int ax = cx + dx;
                        if (ax < 0 || ax >= g) continue;
                        for (int dy = -1; dy <= 1; ++dy) {
                            int ay = cy + dy;
                            if (ay < 0 || ay >= g) continue;
                            for (int dz = -1; dz <= 1; ++dz) {
                                int az = cz + dz;
                                if (az < 0 || az >= g) continue;
                                int j = head[cellId(ax, ay, az)];
                                while (j != -1) {
                                    if (j < i) doPair(i, j);
                                    j = nxt[j];
                                }
                            }
                        }
                    }
                }
            }
        }
        if (!useGrid) {
            for (int i = 0; i < n; ++i) {
                for (int j = 0; j < i; ++j) doPair(i, j);
            }
        }

        for (const auto& a : f) e.force2 += norm2(a);

        if (wall >= 0.0) {
            if (pairOverlap) e.actual = min(wall, 0.5 * minOverlappingDistance);
            else e.actual = min(wall, R);
            if (e.actual > bestR + 1e-12 && e.actual > 0.0) {
                bestR = e.actual;
                best = x;
            }
        }
        return e;
    }

    Result relax(vector<Vec3> x, double R, int maxIterations) {
        vector<Vec3> velocity(n, Vec3{}), force;
        double dt = 0.75;
        double alpha = 0.1;
        int positiveSteps = 0;
        const double D = 2.0 * R;

        for (int it = 0; it < maxIterations; ++it) {
            if ((it & 15) == 0 && chrono::steady_clock::now() >= deadline) break;

            Eval e = evaluate(x, R, force);
            if (e.maxOverlap < 1e-10) return {x, true};
            if (it > 30 && e.force2 < 1e-25) break;
            if (dt < 1e-10) break;

            double power = 0;
            for (int i = 0; i < n; ++i) {
                velocity[i].x += dt * force[i].x;
                velocity[i].y += dt * force[i].y;
                velocity[i].z += dt * force[i].z;
                power += dot(velocity[i], force[i]);
            }

            if (power > 0.0) {
                ++positiveSteps;
                double vv = 0, ff = 0;
                for (int i = 0; i < n; ++i) {
                    vv += norm2(velocity[i]);
                    ff += norm2(force[i]);
                }
                if (vv > 1e-30 && ff > 1e-30) {
                    double factor = sqrt(vv / ff);
                    for (int i = 0; i < n; ++i) {
                        velocity[i].x = (1.0 - alpha) * velocity[i].x + alpha * factor * force[i].x;
                        velocity[i].y = (1.0 - alpha) * velocity[i].y + alpha * factor * force[i].y;
                        velocity[i].z = (1.0 - alpha) * velocity[i].z + alpha * factor * force[i].z;
                    }
                }
                if (positiveSteps > 5) {
                    dt = min(dt * 1.1, 6.0);
                    alpha *= 0.99;
                }
            } else {
                positiveSteps = 0;
                dt *= 0.5;
                alpha = 0.1;
                fill(velocity.begin(), velocity.end(), Vec3{});
            }

            double maxMove = 0;
            for (const auto& v : velocity) {
                maxMove = max(maxMove, fabs(dt * v.x));
                maxMove = max(maxMove, fabs(dt * v.y));
                maxMove = max(maxMove, fabs(dt * v.z));
            }
            double moveScale = 1.0;
            if (maxMove > 0.2 * D && maxMove > 0) {
                moveScale = 0.2 * D / maxMove;
            }

            for (int i = 0; i < n; ++i) {
                x[i].x += dt * moveScale * velocity[i].x;
                x[i].y += dt * moveScale * velocity[i].y;
                x[i].z += dt * moveScale * velocity[i].z;
                x[i].x = max(0.0, min(1.0, x[i].x));
                x[i].y = max(0.0, min(1.0, x[i].y));
                x[i].z = max(0.0, min(1.0, x[i].z));
            }
        }
        return {std::move(x), false};
    }

    void attempt(vector<Vec3> start, double startR) {
        Result first = relax(std::move(start), startR, 350);
        if (!first.feasible) return;

        vector<Vec3> current = std::move(first.x);
        double currentR = startR;

        for (int step = 0; step < 90; ++step) {
            if (chrono::steady_clock::now() >= deadline) return;
            double increment;
            if (currentR < 0.90 * bestR) increment = currentR * 0.02;
            else increment = bestR * 0.002;
            increment = max(increment, 1e-7);
            double target = currentR + increment;
            if (target >= 0.5) return;

            Result next = relax(current, target, 240);
            if (!next.feasible) return;
            current = std::move(next.x);
            currentR = target;
        }
    }

    bool randomSequential(double R, vector<Vec3>& out) {
        out.clear();
        out.reserve(n);
        uniform_real_distribution<double> U(R, 1.0 - R);
        const double need2 = 4.0 * R * R;

        for (int i = 0; i < n; ++i) {
            bool placed = false;
            for (int tries = 0; tries < 3000; ++tries) {
                Vec3 p{U(rng), U(rng), U(rng)};
                bool ok = true;
                for (const auto& q : out) {
                    if (norm2(p - q) < need2) {
                        ok = false;
                        break;
                    }
                }
                if (ok) {
                    out.push_back(p);
                    placed = true;
                    break;
                }
            }
            if (!placed) return false;
        }
        return true;
    }

    void run() {
        int attempts;
        if (n <= 16) attempts = 80;
        else if (n <= 64) attempts = 48;
        else if (n <= 128) attempts = 20;
        else if (n <= 256) attempts = 8;
        else if (n <= 512) attempts = 3;
        else attempts = 1;

        uniform_real_distribution<double> U(-1.0, 1.0);

        for (int a = 0; a < attempts; ++a) {
            if (chrono::steady_clock::now() >= deadline) break;

            if (a == 0) {
                attempt(best, bestR);
                continue;
            }

            if (a % 4 == 3 && n <= 128) {
                vector<Vec3> randomStart;
                double r0 = bestR * 0.65;
                if (randomSequential(r0, randomStart)) {
                    attempt(std::move(randomStart), r0);
                    continue;
                }
            }

            vector<Vec3> start = best;
            double amp = bestR * (0.03 + 0.025 * (a % 8));
            if (a % 9 == 8) amp *= 1.8;
            for (auto& p : start) {
                p.x = max(0.0, min(1.0, p.x + amp * U(rng)));
                p.y = max(0.0, min(1.0, p.y + amp * U(rng)));
                p.z = max(0.0, min(1.0, p.z + amp * U(rng)));
            }
            double startR = bestR * (0.96 - 0.005 * (a % 5));
            attempt(std::move(start), startR);
        }

        if (chrono::steady_clock::now() < deadline) {
            relax(best, min(0.499999, bestR * 1.0003), 600);
        }
    }
};

static long long fccBlockCount(int m) {
    long long E = m / 2 + 1;
    long long O = m + 1 - E;
    return E * E * E + 3LL * E * O * O;
}

static long long bccBlockCount(int m) {
    long long E = m / 2 + 1;
    long long O = m + 1 - E;
    return E * E * E + O * O * O;
}

static void largeFallback(int n) {
    int k = max(1, (int)ceil(cbrt((double)n) - 1e-12));
    while (1LL * k * k * k < n) ++k;

    int mf = 0;
    while (fccBlockCount(mf) < n) ++mf;
    int mb = 0;
    while (bccBlockCount(mb) < n) ++mb;

    const double sq2 = sqrt(2.0), sq3 = sqrt(3.0);
    double rs = 1.0 / (2.0 * k);
    double rf = sq2 / (2.0 * (mf + sq2));
    double rb = sq3 / (2.0 * (mb + sq3));

    cout << setprecision(17);

    if (rs >= rf && rs >= rb) {
        int printed = 0;
        for (int i = 0; i < k && printed < n; ++i) {
            for (int j = 0; j < k && printed < n; ++j) {

    }
}

static void softOptimizeStage(vector<Point>& points, double relativeSigma,
                              int iterations, RNG& rng) {
    if (iterations <= 0) return;

    double currentDistance = minimumDistance(points);
    double sigma = max(1e-12, relativeSigma * currentDistance);
    int stalled = 0;

    for (int iteration = 0; iteration < iterations; ++iteration) {
        double cutoff = min(4.0, currentDistance + 12.0 * sigma);
        SoftResult current = collectSoft(points, sigma, cutoff);

        if (current.pairs.empty() || !isfinite(current.minimum)) break;

        vector<Point> gradient(points.size());
        double maxNorm = 0.0;

        for (const PairObservation& observation : current.pairs) {
            double d = sqrt(observation.d2);
            if (d < 1e-15) continue;

            double weight = exp(-(d - current.minimum) / sigma);
            int i = observation.i;
            int j = observation.j;

            double ux = (points[i].x - points[j].x) / d;
            double uy = (points[i].y - points[j].y) / d;
            double uz = (points[i].z - points[j].z) / d;

            gradient[i].x += weight * ux;
            gradient[i].y += weight * uy;
            gradient[i].z += weight * uz;
            gradient[j].x -= weight * ux;
            gradient[j].y -= weight * uy;
            gradient[j].z -= weight * uz;
        }

        for (const Point& g : gradient)
            maxNorm = max(maxNorm, sqrt(g.x * g.x + g.y * g.y + g.z * g.z));

        if (maxNorm < 1e-18) {
            perturbCritical(points, 2e-4 * currentDistance, rng);
            continue;
        }

        double scale = 0.010 * currentDistance / maxNorm;
        bool accepted = false;

        const double factors[4] = {1.0, 0.5, 0.25, 0.125};
        for (double factor : factors) {
            vector<Point> trial = points;
            for (int i = 0; i < int(points.size()); ++i) {
                trial[i].x += factor * scale * gradient[i].x;
                trial[i].y += factor * scale * gradient[i].y;
                trial[i].z += factor * scale * gradient[i].z;
                trial[i] = clampPoint(trial[i]);
            }

            double value = softValue(trial, sigma, cutoff);
            if (value > current.value + 1e-15) {
                points.swap(trial);
                current.value = value;
                currentDistance = minimumDistance(points);
                accepted = true;
                stalled = 0;
                break;
            }
        }

        if (!accepted) {
            ++stalled;
            if (stalled >= 12) {
                perturbCritical(points, 2.5e-4 * currentDistance, rng);
                stalled = 0;
            }
        }
    }
}

static void relaxAtTarget(vector<Point>& points, double target, int iterations) {
    int n = int(points.size());
    double cutoff = target * (1.0 + 1e-10) + 1e-12;

    for (int iteration = 0; iteration < iterations; ++iteration) {
        SpatialGrid grid(points, cutoff);
        vector<Point> movement(n);
        bool any = false;

        grid.forEachPair([&](int i, int j, double d2) {
            double d = sqrt(d2);
            if (d >= target) return;
            any = true;

            double overlap = target - d;
            double amount = 0.30 * overlap;
            double inv = 1.0 / max(d, 1e-15);

            double ux = (points[i].x - points[j].x) * inv;
            double uy = (points[i].y - points[j].y) * inv;
            double uz = (points[i].z - points[j].z) * inv;

            movement[i].x += amount * ux;
            movement[i].y += amount * uy;
            movement[i].z += amount * uz;
            movement[j].x -= amount * ux;
            movement[j].y -= amount * uy;
            movement[j].z -= amount * uz;
        });

        if (!any) break;

        double cap = 0.04 * target;
        for (int i = 0; i < n; ++i) {
            double len = sqrt(movement[i].x * movement[i].x +
                              movement[i].y * movement[i].y +
                              movement[i].z * movement[i].z);
            if (len > cap) movement[i] *= cap / len;
            points[i] = clampPoint(points[i] + movement[i]);
        }
    }
}

static vector<Point> improveWithTarget(vector<Point> points, int rounds, int iterations) {
    vector<Point> best = points;
    double bestDistance = minimumDistance(best);
    double epsilon = 0.004;

    for (int round = 0; round < rounds; ++round) {
        double currentDistance = minimumDistance(points);
        vector<Point> trial = points;
        relaxAtTarget(trial, currentDistance * (1.0 + epsilon), iterations);
        double trialDistance = minimumDistance(trial);

        if (trialDistance > bestDistance + 1e-13) {
            best.swap(trial);
            bestDistance = trialDistance;
            points = best;
            epsilon = min(0.010, epsilon * 1.35);
        } else {
            points = best;
            epsilon *= 0.45;
            if (epsilon < 2e-5) break;
        }
    }

    return best;
}

static vector<Point> optimizeCandidate(vector<Point> points, int totalIterations,
                                        bool fullRun, RNG& rng) {
    vector<Point> best = points;
    double bestDistance = minimumDistance(best);
    vector<Point> work = points;

    auto runStage = [&](double sigma, int iterations) {
        softOptimizeStage(work, sigma, iterations, rng);
        double d = minimumDistance(work);

        if (d > bestDistance) {
            bestDistance = d;
            best = work;
        }

        if (d < bestDistance * 0.995)
            work = best;
    };

    if (fullRun) {
        int q = totalIterations / 4;
        runStage(0.060, max(1, int(totalIterations * 0.20)));
        runStage(0.022, max(1, int(totalIterations * 0.25)));
        runStage(0.007, max(1, int(totalIterations * 0.30)));
        runStage(0.002, max(1, q));
    } else {
        runStage(0.040, max(1, int(totalIterations * 0.40)));
        runStage(0.010, max(1, int(totalIterations * 0.60)));
    }

    if (fullRun) {
        work = improveWithTarget(work, 8, 35);
        double d = minimumDistance(work);
        if (d > bestDistance) {
            bestDistance = d;
            best = work;
        }
    }

    return best;
}

static void removeRedundantPoints(vector<Point>& points, int required, RNG& rng) {
    int total = int(points.size());
    if (total <= required) return;

    normalizePoints(points);
    double dmin = minimumDistance(points);
    double cutoff = 1.28 * dmin + 1e-12;
    SpatialGrid grid(points, cutoff);
    vector<int> degree(total, 0);

    grid.forEachPair([&](int, int, double) {
        ++degree[0];
    });

    grid.forEachPair([&](int i, int j, double) {
        ++degree[i];
        ++degree[j];
    });

    vector<pair<double, int>> order;
    order.reserve(total);
    for (int i = 0; i < total; ++i)
        order.push_back({double(degree[i]) + 0.85 * rng.uniform(), i});

    sort(order.begin(), order.end(), [](const auto& a, const auto& b) {
        if (a.first != b.first) return a.first > b.first;
        return a.second < b.second;
    });

    int remove = total - required;
    vector<bool> deleted(total, false);
    for (int i = 0; i < remove; ++i)
        deleted[order[i].second] = true;

    vector<Point> kept;
    kept.reserve(required);
    for (int i = 0; i < total; ++i)
        if (!deleted[i]) kept.push_back(points[i]);

    points.swap(kept);
    normalizePoints(points);
}

struct FccSpec {
    int a, b, c, parity;
    int count;
    double theoreticalDistance;
    double score;
};

static int parityCount(int a, int b, int c, int parity) {
    long long total = 1LL * a * b * c;
    int sign = (a & 1) * (b & 1) * (c & 1);
    int even = int((total + sign) / 2);
    return parity == 0 ? even : int(total - even);
}

static int cornerCount(int a, int b, int c, int parity) {
    int count = 0;
    for (int x = 0; x < 2; ++x)
        for (int y = 0; y < 2; ++y)
            for (int z = 0; z < 2; ++z)
                if (((x ? a - 1 : 0) + (y ? b - 1 : 0) +
                     (z ? c - 1 : 0)) % 2 == parity)
                    ++count;
    return count;
}

static vector<FccSpec> findFccSpecs(int n) {
    int base = max(2, int(ceil(cbrt(2.0 * n))));
    int low = max(2, base - 6);
    int high = base + 6;
    vector<FccSpec> specs;

    for (int a = low; a <= high; ++a) {
        for (int b = low; b <= high; ++b) {
            for (int c = low; c <= high; ++c) {
                long long cells = 1LL * a * b * c;
                if (cells > 3LL * n) continue;

                double sa = 1.0 / max(1, a - 1);
                double sb = 1.0 / max(1, b - 1);
                double sc = 1.0 / max(1, c - 1);
                double delta = numeric_limits<double>::infinity();

                if (a >= 3) delta = min(delta, 2.0 * sa);
                if (b >= 3) delta = min(delta, 2.0 * sb);
                if (c >= 3) delta = min(delta, 2.0 * sc);

                if (a >= 2 && b >= 2) delta = min(delta, hypot(sa, sb));
                if (a >= 2 && c >= 2) delta = min(delta, hypot(sa, sc));
                if (b >= 2 && c >= 2) delta = min(delta, hypot(sb, sc));

                if (!isfinite(delta)) continue;

                for (int parity = 0; parity < 2; ++parity) {
                    int count = parityCount(a, b, c, parity);
                    if (count < n || count > int(1.55 * n)) continue;

                    double holes = double(count - n) / n;
                    int corners = cornerCount(a, b, c, parity);
                    double score = delta * (1.0 - 0.12 * holes) + 1e-7 * corners;
                    specs.push_back({a, b, c, parity, count, delta, score});
                }
            }
        }
    }

    sort(specs.begin(), specs.end(), [](const FccSpec& x, const FccSpec& y) {
        return x.score > y.score;
    });

    vector<FccSpec> unique;
    set<array<int, 3>> used;
    for (const FccSpec& s : specs) {
        array<int, 3> key = {s.a, s.b, s.c};
        if (used.insert(key).second)
            unique.push_back(s);
    }
    return unique;
}

static vector<Point> makeFcc(const FccSpec& spec, int n, RNG& rng) {
    vector<Point> points;
    points.reserve(spec.count);

    for (int i = 0; i < spec.a; ++i) {
        for (int j = 0; j < spec.b; ++j) {
            for (int k = 0; k < spec.c; ++k) {
                if ((i + j + k) % 2 != spec.parity) continue;
                points.push_back({
                    double(i) / max(1, spec.a - 1),
                    double(j) / max(1, spec.b - 1),
                    double(k) / max(1, spec.c - 1)
                });
            }
        }
    }

    removeRedundantPoints(points, n, rng);
    return points;
}

static Point rotatePoint(Point p, double ax, double ay, double az) {
    double cx = cos(ax), sx = sin(ax);
    double cy = cos(ay), sy = sin(ay);
    double cz = cos(az), sz = sin(az);

    double y = p.y * cx - p.z * sx;
    double z = p.y * sx + p.z * cx;
    p.y = y; p.z = z;

    double x = p.x * cy + p.z * sy;
    z = -p.x * sy + p.z * cy;
    p.x = x; p.z = z;

    x = p.x * cz - p.y * sz;
    y = p.x * sz + p.y * cz;
    p.x = x; p.y = y;

    return p;
}

static void improveOrientation(vector<Point>& points, RNG& rng) {
    if (points.size() > 10000) return;

    vector<Point> best = points;
    double bestDistance = minimumDistance(best);

    for (int trial = 0; trial < 24; ++trial) {
        double ax = (2.0 * rng.uniform() - 1.0) * 0.10;
        double ay = (2.0 * rng.uniform() - 1.0) * 0.10;
        double az = (2.0 * rng.uniform() - 1.0) * 0.10;

        vector<Point> rotated;
        rotated.reserve(points.size());
        for (Point p : points)
            rotated.push_back(rotatePoint(p, ax, ay, az));

        normalizePoints(rotated);
        double d = minimumDistance(rotated);
        if (d > bestDistance + 1e-13) {
            bestDistance = d;
            best.swap(rotated);
        }
    }

    points.swap(best);
}

static vector<Point> makeSimpleGrid(int a, int b, int c) {
    vector<Point> points;
    points.reserve(a * b * c);

    for (int i = 0; i < a; ++i)
        for (int j = 0; j < b; ++j)
            for (int k = 0; k < c; ++k)
                points.push_back({
                    double(i) / max(1, a - 1),
                    double(j) / max(1, b - 1),
                    double(k) / max(1, c - 1)
                });

    normalizePoints(points);
    return points;
}

static vector<array<int, 3>> findSimpleGrids(int n) {
    vector<pair<double, array<int, 3>>> grids;

    for (int a = 2; 1LL * a * a * a <= n; ++a) {
        if (n % a != 0) continue;
        int remaining = n / a;

        for (int b = a; 1LL * b * b <= remaining; ++b) {
            if (remaining % b != 0) continue;
            int c = remaining / b;
            double score = 1.0 / max(1, a - 1);
            score = min(score, 1.0 / max(1, b - 1));
            score = min(score, 1.0 / max(1, c - 1));
            grids.push_back({score, {a, b, c}});
        }
    }

    sort(grids.begin(), grids.end(), [](const auto& x, const auto& y) {
        return x.first > y.first;
    });

    vector<array<int, 3>> result;
    for (const auto& g : grids) {
        if (result.size() >= 3) break;
        result.push_back(g.second);
    }
    return result;
}

static vector<Point> makeBcc(int a, int b, int c, int n, RNG& rng) {
    vector<Point> points;
    points.reserve(a * b * c + (a - 1) * (b - 1) * (c - 1));

    for (int i = 0; i < a; ++i)
        for (int j = 0; j < b; ++j)
            for (int k = 0; k < c; ++k)
                points.push_back({
                    double(i) / max(1, a - 1),
                    double(j) / max(1, b - 1),
                    double(k) / max(1, c - 1)
                });

    for (int i = 0; i + 1 < a; ++i)
        for (int j = 0; j + 1 < b; ++j)
            for (int k = 0; k + 1 < c; ++k)
                points.push_back({
                    (i + 0.5) / max(1, a - 1),
                    (j + 0.5) / max(1, b - 1),
                    (k + 0.5) / max(1, c - 1)
                });

    removeRedundantPoints(points, n, rng);
    return points;
}
