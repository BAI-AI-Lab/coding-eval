题面

来源：USACO 官网。模型收到的是同一份题面的文字。

On National Milk Day, Farmer John is offering exclusive prices on buckets of milk! He has $N$ ($1 \leq N \leq 10^5$) deals numbered from $1$ to $N$. For the $i$'th deal, he is offering $2^{i-1}$ buckets of milk for $a_i$ ($1 \leq a_i \leq 10^9, a_i < a_{i+1}$) moonies. The same deal may be taken any non-negative integer number of times.

You are thinking about $Q$ ($1 \leq Q \leq 10^4$) independent queries. For each query, you have an integer $x$ ($1 \leq x \leq 10^9$) in mind and wonder what is the minimum cost to purchase at least $x$ buckets of milk.

INPUT FORMAT (input arrives from the terminal / stdin):

The first line contains two integers $N$ and $Q$.

The following line contains $a_1, a_2, \ldots, a_N$.

Each of the following $Q$ lines contains an integer $x$, representing a query.

OUTPUT FORMAT (print output to the terminal / stdout):

For each query, output the minimum cost on a new line.

Note that the large size of integers involved in this problem may require the use of 64-bit integer data types (e.g., a "long long" in C/C++).

SAMPLE INPUT:

2 4
10 15
1
2
6
7

SAMPLE OUTPUT:

10
15
45
55
In the example above, Farmer John is offering 2 deals: 1 bucket of milk for 10 moonies and 2 buckets of milk for 15 moonies.

The cheapest cost to buy 1 bucket is just the cost of the 1 bucket deal and the cheapest cost to buy 2 buckets is just the cost of the 2 bucket deal.

To get 6 buckets, the cheapest way is to purchase 3 of the 2 bucket deal for a total of 45 moonies.

To get 7 buckets, the cheapest way is to purchase 3 of the 2 bucket deal and 1 of the 1 bucket deal for a total of 55 moonies.

SCORING:

  • Inputs 3-4: $N \leq 2$
  • Inputs 5-8: $N \leq 10$

import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, q = data[0], data[1]
    prices = data[2:2 + n]
    queries = data[2 + n:2 + n + q]

    # Deal 31 already supplies 2^30 > 10^9 buckets. Every later deal
    # costs more, so none of them can improve an answer.
    limit = min(n, 31)
    deals = []  # (buckets supplied, cost), retaining only useful deals
    exact_cost = 0

    for i in range(limit):
        cost = prices[i]
        if i == 0:
            deals.append((1, cost))
            exact_cost = cost
            continue

        previous_option = 2 * exact_cost
        if cost < previous_option:
            deals.append((1 << i, cost))
            exact_cost = cost
        else:
            exact_cost = previous_option

    def calculate(j, amount):
        if j == 0:
            return amount * deals[0][1]

        size, cost = deals[j]
        whole, remainder = divmod(amount, size)

        # Either buy one extra large deal, or buy `whole` large deals
        # and optimally cover the remainder with smaller deals.
        return min(
            (whole + 1) * cost,
            whole * cost + calculate(j - 1, remainder)
        )

    last = len(deals) - 1
    answers = [str(calculate(last, x)) for x in queries]
    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    main()

import sys


def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, q = data[0], data[1]
    a = data[2:2 + n]
    queries = data[2 + n:2 + n + q]

    max_x = max(queries)
    L = max_x.bit_length()

    INF = 10 ** 30
    c = [0] * (L + 1)

    c[0] = a[0]
    for k in range(1, L + 1):
        deal_cost = a[k] if k < n else INF
        c[k] = min(deal_cost, 2 * c[k - 1])

    answers = []

    for x in queries:
        exact_cost = 0
        for i in range(L + 1):
            if (x >> i) & 1:
                exact_cost += c[i]

        ans = exact_cost
        higher_cost = 0

        for k in range(L, -1, -1):
            if (x >> k) & 1:
                higher_cost += c[k]
            else:
                ans = min(ans, higher_cost + c[k])

        answers.append(str(ans))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    main()

import sys


def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, q = data[0], data[1]
    prices = data[2:2 + n]
    queries = data[2 + n:2 + n + q]

    # We need packages through the next power of two above max(queries).
    levels = max(queries).bit_length() + 1

    # package[k] = minimum cost to buy exactly 2^k buckets.
    package = [0] * levels
    package[0] = prices[0]

    for k in range(1, levels):
        # Buy two packages of size 2^(k-1).
        package[k] = 2 * package[k - 1]

        # Or buy the deal containing exactly 2^k buckets directly.
        if k < n and prices[k] < package[k]:
            package[k] = prices[k]

    answers = []

    for x in queries:
        highest = x.bit_length() - 1

        # Buying exactly the next power of two is always sufficient.
        best = package[highest + 1]

        # Cost of the set bits of x strictly above the current bit.
        prefix_cost = 0

        for k in range(highest, -1, -1):
            if (x >> k) & 1:
                prefix_cost += package[k]
            else:
                # Keep the higher bits of x, set this bit to 1,
                # and clear all lower bits.
                candidate = prefix_cost + package[k]
                if candidate < best:
                    best = candidate

        # Also consider buying exactly x buckets.
        if prefix_cost < best:
            best = prefix_cost

        answers.append(str(best))

    sys.stdout.write("\n".join(answers) + "\n")


if __name__ == "__main__":
    solve()
