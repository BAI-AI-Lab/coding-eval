原理

用 LiveCodeBench 的官方题目、提示词和判题程序评测，再对判为失败的答案复核，最后测量通过答案的运行效率和代码指标。

选题

release_v6 最新 100 题中取最新的中等 10、困难 25 题。

生成

官方提示词，每题调用模型 API 1 次，提取回答中的最后一个代码块。

判题

AtCoder 题作为完整程序读写标准输入输出，LeetCode 题调用给定函数；隐藏测试全过才算通过。

复核

用真实 stdin/stdout 重跑全部 AtCoder 答案，多解题用校验器。

代码分析

通过的答案绑核重跑，测 CPU 时间与峰值内存；radon、pyflakes 统计代码指标。

费用官方单价 × token，DeepSeek 按调用时段区分峰谷；用账户余额变化核对

为什么用最新的题

LiveCodeBench 持续从 AtCoder、LeetCode、Codeforces 收集比赛题并标注发布日期，可以只用某个日期之后的题，降低训练数据污染。本次 35 题发布于 2025-03-15 至 2025-04-06，仍早于三个模型的发布时间，不排除污染（见“结果 › 局限”）。

判分与复核

LCB 判题程序在标准输入输出上有缺陷，测试数据也有错误。只用原始判分会低估模型，甚至颠倒排名。

复核方法：26 道 AtCoder 题 × 3 个模型 = 78 份答案，作为独立 Python 进程用真实 stdin/stdout 运行官方全部测试（每个测试 6 秒）。两道多解题用按题意编写的校验器，其余逐 token 比对。LCB 判为通过的答案复核后全部仍通过。LeetCode 9 题为函数调用，不受上述问题影响，沿用 LCB 判分。上述问题均出自 LCB 官方判题代码与数据（本评测固定的版本），未作修改。Kimi abc398_g 在 LCB 中报 IndexError，也是 readline 问题导致；换成真实输入后仍有 4/43 个测试答案错误，按失败计。

性能测量

只比较复核后通过的答案，所有输出都校验正确后才计入。

项目设置
对象复核后通过的答案（Kimi 33 份，不含 abc398_g、abc399_e；DeepSeek 各 35 份）
运行每次运行都是一个全新的 Python 3.11 进程（LCB 环境），绑定到单个 CPU 核；共 11,124 次，输出全部正确
计时AtCoder：进程 CPU 时间（rusage）扣除启动基线 25.7 ms；LeetCode：只计 Solution 方法调用的 CPU 时间
内存进程峰值常驻内存（ru_maxrss）；空程序为 12.1 MB
重复每个测试 3 次、三个模型轮流先跑，取中位数；同一测试 3 次的离散度中位数 2.0%，P90 6.4%
可比题最慢答案扣除启动后仍 ≥ 0.1 秒的题，共 13 题；其余 22 题官方测试太小，耗时主要是启动开销，不比较

静态指标

  • 有效行：不含空行和注释的代码行（radon raw）。注释行含文档字符串。
  • 圈复杂度：每份答案所有函数与方法的圈复杂度之和（radon cc）。
  • 可维护性指数：0–100，越高越好（radon mi，含多行字符串）。
  • 嵌套深度：语法树中复合语句（if、for、while、with、try、def、class、match）的最大嵌套层数。
  • pyflakes 警告：未使用的变量、未定义的名字等。

这些指标只描述代码形态，不评价可读性、命名等主观项。

Kimi K3.1 Pro

  • 变更：在 K3 上大幅增加后训练算力，覆盖数百个领域联合 RL；重做 RL 框架、长上下文推理、沙箱、rollout 调度。
  • 官方提升方向：编程、3D 建模（直接写 Blender / CAD 脚本）、金融研究（内部 Financial Research 比 K3 高 11.6 分）、智能体。
  • 安全：中期训练与 RL 数据剔除网络安全内容；xdev-bench-hard pass@3 81.0%（不剔除 90.5%）。
  • 高速版 kimi-k3.1-pro-highspeed：速度 2–3 倍，价格 2 倍。K2 系列 2026 年底下线。
  • 使用限制：充值 ≥ 1 美元解锁；累计充值决定并发 / TPM；temperature、top_p、n、penalty 不可传。
  • 官方文档中的编程基准分数为占位符（“[xx.x%]”），无可引用数据。

DeepSeek-V4.1-Flash

  • 2026-09-10 发布：20 层因果编码器 + 20 层解码器；MoE 1 共享 + 384 路由专家，每 token 激活 6 个；KV 缓存 890 字节/token，HBM 为上一代 1/4、SSD 为 1/8；原生视觉；降价；V4-Flash 下线。
  • 2026-10-17 更新为 1017 版（新 / 旧）：Terminal-Bench 4.0 42.3 / 31.2，DeepSWE v1.1 77.0 / 74.2，ProgramBench 29.1 / 20.3，NL2Repo 68.2 / 65.4，HLE 42.6 / 36.8；输出更短、耗时更少；价格与调用方式不变。
  • Codeforces 3471（max 档；同表 V4-Pro 3348）。输出单价为 V4-Pro 的 30%、Kimi K3.1 Pro 的 12%。

DeepSeek-V4-Pro

  • 2026-04-24 首发；2026-08-13 GA：HLE 42.7 / 60.0（无 / 有工具），Terminal-Bench 2.1 87.9，DeepSWE 62.7，NL2Repo 61.5，Toolathlon-Verified 74.1；引入 low/high/max 三档；2026-08-16 起峰谷定价。
